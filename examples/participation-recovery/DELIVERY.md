# 参途 · 本机使用与交接

参途帮助混合活动主办方把参加需要连接到具体时段、实际服务入口、最终端演练证据及最新版确认；临时换场、换流或更新资料后，明确哪些路径必须重新演练和交接。

## 启动

需要 Node.js 20 以上与现代浏览器；日常使用不需要安装开发依赖、账户或外部服务。在本项目目录执行：

```sh
npm start
```

打开 `http://127.0.0.1:4189/`。关闭终端或按 `Ctrl+C` 停止。采用固定端口、相同浏览器继续使用，可读取同一来源下的本地保存。不要直接双击 HTML；浏览器模块需要 HTTP 入口。

## 从活动输入到交接

1. 从空白活动开始，填写活动名称和日期，添加时段。演示数据仅供合成演练，不能当成真实服务证据。
2. 为时段添加路线、字幕或资料服务，填写负责人和参加者实际使用的地址/路线说明。资料有提前交付要求时必须填写期限。
3. 建立参加路径，使用参加者代号和对应时段，勾选所需服务。每条路径至少选择一项，可按实际已接受需要组合；不要把未勾选服务误认为无需，完整需要必须由活动协调人实际确定。
4. 从参加者终端演练每个服务，录入检查人、时间、通过/失败、实际观察和资料交付时间。软件记录你提交的观察，不能自行探测现实服务。
5. 按路径查看缺口，安排相关负责人修复；补齐证据后，负责人和参加者分别确认最新版。仅有资源预订、承诺或旧版本确认不足以就绪。
6. 发生变更时通过“变更入口”更新实际安排并记录原因。同地址的资料、字幕或服务内容已实际替换时，勾选“内容或服务已实际更新（地址可以不变）”，说明具体变化并保存；无需改名或伪造地址。也可变更时段安排或调整路径关联的服务，纠正录入或响应新需要。受影响的旧证据和版本确认保留为历史，但不再放行最新路径；无关路径保持不变。资源变更后重新演练并确认，时段或路径调整后核对当前证据及最新安排再确认，完成后再交接。
7. 导出中文活动总交接包给内部协调人使用，按负责人下载任务稿，按参加路径下载专属参加者指引，再导出 JSON 全量备份。活动总包与 JSON 含全部记录，不应作为个人指引发送。参途不会替你发送邮件或联系任何人。

## 最终端演练方法

| 服务 | 实际人员要核验的终点 | 不能用来替代的证据 |
|---|---|---|
| 路线 | 按参加者所需方式走到对应房间或入口，说明入口、障碍、支持及备用路线 | 仅写“场地已预订” |
| 字幕 | 从实际观看入口进入，在参加者设备上能取得并开启字幕，检查可见性、可读性和与内容对应情况 | 仅麦克风、收音或字幕供应商排期通过 |
| 资料 | 打开当前版本，实际检查所需调整方式、内容可用性和提前收到时间 | 仅文件存在、格式扩展名正确或讲者已承诺 |

观察记录需清楚描述做了什么、看到了什么和剩余限制。字幕通过还需分别确认“可取得、可开启、可读”三个终点；音频测试不满足这些条件。软件不会对观察真假、资料适配质量、字幕准确度或现场障碍自动作保证。不要录入未做过的检查。

## 失败与恢复

| 情况 | 处理方式 |
|---|---|
| 路径缺证、证据失败 | 按缺口中的服务及负责人修复，再记录新的最终端观察；旧失败保留 |
| 换场、换流或同地址更新内容/服务 | 用“变更入口”登记；同地址实际更新时勾选内容更新并填写具体原因。系统生成新版本，关联路径须重新演练、负责人和参加者分别重确认；查看证据及中文总交接包可追溯版本更新 |
| 没有实际变化、仅误点或补写说明 | 不勾选内容更新；同字段保存会被拒绝，当前版本和就绪保持。等价时区或日期格式变化不会误升版 |
| 同版本新增演练观察 | 记录新观察后重新双向确认，旧确认不能代替对新观察的确认 |
| 新版资料借用更新前交付时间 | 实际内容更新后的资料需填写新版实际送达时间；旧时间会被拒绝。期限后换版仍保留准备机会损失，补演练不能将其恢复为提前就绪 |
| 资料错过原提前期限 | 迟交不能恢复已经失去的准备时间；保留迟交缺口，交接中明确限制，实际人员另行协调可接受的安排 |
| 导入格式错误或引用无效 | 显示中文错误，当前活动仍保留；修复备份格式或换用有效备份 |
| 浏览器存储不可用或空间不足 | 关注保存提示，立即导出 JSON；不要只依赖刷新恢复 |
| 换设备、换端口或清浏览器数据 | 从原来源导出 JSON，再在新入口导入；本地数据不会自动跨设备同步 |

导入备份和建立新活动前先导出当前活动。导入是替换当前活动，不是合并多个活动；保留下载文件才能恢复替换前的数据。JSON 是便携工作记录，不是防篡改证明。

## 隐私与作业边界

数据在当前浏览器本地保存，不上传。使用代号，避免记录不必要的诊断、身份、联系方式或个人敏感需要；下载文件中也包含活动输入和观察记录，需按组织内部要求存放和分享。打开外部服务地址会进入对应网站，由操作者自行决定是否访问。

负责人任务稿包含与其服务相关的路径名称和缺口，请使用匿名路径名称，并由组织者确认分享范围。参加者指引只列所选路径的当前安排；活动总包和完整备份属于协调员内部档案。本地确认记录不提供登录、身份认证或现实权限验证。

交接是当前记录及缺口的快照，发送前重新确认版本。现场字幕、专业人员、场地可达性、实际资料质量和真实参加者接受仍由实际人员履约和核验。本交付证明本地工具可用，不证明活动成功、真实用户采用、成交或盈利。收入 $0，真实用户 0。

## 验证与维护

开发检查在本目录执行，不需要 Auto Company 运行环境：

```sh
npm ci
npx playwright install chromium
npm test
npm run test:browser
```

浏览器检查自行启动本机页面。核心与恢复检查覆盖等价时间、实际内容更新、历史证据与双确认；浏览器检查覆盖真实录入、同地址更新、独立路径不受影响、下载、导入恢复与窄屏布局。测试输入均为构造数据，结果不能代替现实活动履约。测试输出在本目录 `.auto-company/`，修改后请重新执行有关检查。
