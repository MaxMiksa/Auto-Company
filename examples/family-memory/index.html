今天，谁愿意一起讲？

建议 2–5 位亲属轮流使用同一台设备；也可以先一个人试用。

一场活动的约定

先听，再补充。

  1. 挑一个小主题，留出 20–40 分钟。
  2. 每人讲一段；不愿说，可以跳过。
  3. 记忆不同，就把不同并排留下。
  4. 导出前，一起确认署名和公开范围。

这是本地活动手册，不是远程多人协作。输入不会上传；同一设备上的人可以看到本地内容，包括私密记录。

准备好后，把设备交给第一位讲述者。
