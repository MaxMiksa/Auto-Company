# 家族共忆交互说明

主要使用者是一位主持家庭活动的亲属：在同一台设备上，邀请自愿参与者轮流讲述，把不同记得并列，留下有署名和原话出处的共同故事。单人也可试用；建议 2–5 位自愿亲属。产品不承担远程实时协作，不上传内容，不自动判断事实。

| 步骤 | 使用者完成的事 | 可观察结果 |
| --- | --- | --- |
| 准备 | 命名活动，添加明确同意的署名参与者 | 活动摘要及参与者列表更新 |
| 讲述 | 输入公开或本地私密原话，保留情境线索 | 原话有署名、范围和编号，可编辑、撤回 |
| 互问 | 从公开原话出发向另一位参与者询问 | 可公开回应或自愿跳过；回应进入署名原话 |
| 共同故事 | 选择公开原话，整理串联文字及不同记得 | 故事保留引用来源，可修改、导出与打印 |

视觉采用家庭故事手册：纸白底、暖灰桌面、墨绿主色与朱砂章节提示；中文宋体标题、横排目录、手册页码、细线与留白。没有外部资源或字体。手机改为单列，同一导航保留章节位置。所有输入具有标签，步骤按钮可由键盘操作，操作结果由提示区宣读。

完整备份包含私密原话，须妥善保管。故事导出与打印仅包括公开内容，但手动写入公开字段的敏感文字需要自行检查。撤回清理明确关联的原话、互问、回应和故事整理文字；无法识别手动复制到无引用字段的同内容，无法收回已有外部副本。撤销参与仍保留参与者称呼，需彻底去除时可备份后清空重建。

缓存键为 `family-memory-session-v1`。保存失败时仍保留本页内容，提示下载备份，不声称保存成功。损坏缓存不会自动覆盖；界面提供原始缓存下载，用户明确同意后才能重新开始。格式错误或超限的导入保留现有活动。清空和成功导入在下一次修改或本页关闭前可以撤销一次；普通修改会丢弃旧快照，避免隐私撤回后被旧快照恢复。撤销会替换当前内容，因此需要确认。隐私撤回及活动替换会清理未提交的编辑和提问草稿。

新活动不默认载入合成示例。虚构示例按钮独立，并在人物、内容、活动标题中标记虚构；它不代表真实使用或商业证据。

`docs/product-logo-prompt.md` 在本运行仓库中缺失。输入图标 `icon.svg` 使用两张交叠页与连接的墨绿形状，限制三种颜色、基础几何与 `viewBox`；页面标识及 favicon 引用程序生成的 `/auto-company-icon.svg`，没有手动创建该文件。
