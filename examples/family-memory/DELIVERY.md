# 家族共忆 · 使用与交接

家族共忆是一个简体中文本地浏览器手册，帮助主办者与自愿亲属在同一设备轮流讲述、互相提问，留下一份署名、保留不同说法、可追溯原话的共同故事。可一人试用，建议2–5位自愿亲属。演示材料是虚构内容。

## 本机打开

在项目目录 本目录 中运行：

```sh
npm start
```

打开 <http://127.0.0.1:4187>。保持终端运行，结束时按 `Ctrl+C`。需要 Node.js 20 以上和现代浏览器；`npm start` 使用 Node 自带的本机 HTTP 服务，不需要安装开发依赖、注册、登录或连接外部服务。请通过本机 HTTP 入口打开，直接双击HTML可能阻止模块加载。

浏览器数据按入口地址隔离，端口变化或使用另一个浏览器不会自动带入原活动；先备份，再在新入口导入。循环中的预览只在本周期保留，交接使用上述自行启动方式。

## 一场活动的完整步骤

| 步骤 | 操作与结果 |
|---|---|
| 准备 | 填写活动主题、日期、地点和旧照/往事线索；添加亲属姓名，确认其自愿参与。照片线索是文字说明，不上传图片 |
| 讲述 | 每人轮流在同一设备输入署名原话，可填写事件线索；不愿共同留存的内容选择私密，任何人都可以跳过 |
| 互问 | 选择提问者、回答者及来源原话，录入想追问的问题；回答产生回答者署名原话，也可选择跳过 |
| 共同故事 | 人工勾选有关的公开原话，起标题、整理注记，把不同说法写入分歧栏；结果保留来源，软件不判断谁的记忆正确 |
| 留存 | 下载共同故事Markdown或打印；下载完整JSON备份，可在同一产品中恢复继续活动 |

主持建议：先说明任何问题都可以不回答；用“一件你愿意讲的事”开始，再问“你记得的细节是什么”“还有谁记得不同的版本”；结束前一起阅读共同故事，允许修改或撤回。活动时长由使用者掌握，本地软件检查不证明真人参与体验或省时。

## 保存、恢复和撤回

浏览器会尝试在本机自动保存。请定期下载完整JSON备份，尤其在清空活动、清理浏览器或换设备前。隐私模式、浏览器配额或禁止存储可能使自动保存失效；界面会提示，仍可下载当前成果和备份。完整备份包含私密原话，只应交给获授权的持有人。

可以同时填写多个问题的回应。未点击“保存回应”的文字按问题分别保留在当前页面；保存另一条回应、切换步骤、添加其他记录不会清空它们。回答草稿尚未成为正式原话，不写入本地活动缓存、JSON备份、共同故事或打印；刷新、关闭页面前请逐条保存。跳过会清除该问题草稿；撤回问题、来源原话或参与同意会清理相关草稿，保留其他无关问题的输入。修改来源原话后相关内容需要重新核对。清空、载入示例、成功恢复备份或撤销活动替换会清除本页互问、原话和故事草稿；被拒绝或取消的替换不会清除。

导入备份会替换当前活动，应先保存当前备份。只有完整有效的数据才会替换；坏文件会被拒绝，原活动保留。遇到损坏的本地缓存时，可保存原始缓存供人工恢复，或明确重新开始，不能把“已拒绝”当作恢复成功。

编辑或撤回原话会清理有关问题、回答和共同故事中的派生文字，避免历史实验中发现的标题残留。问题也可单独撤回，其回答及关联派生内容一并清理，原始来源原话保留。清理后请重新审阅故事。私密原话不进入共同故事导出。如果曾手动把内容复制到活动标题、无来源问题或其他无关联故事，软件不能按语义识别，请自行检查并删改。参与者称呼可修改；撤销参与会清除该人的原话及关联内容，但参与者表仍保留称呼，彻底移除可清空活动后重建。清空或成功恢复备份后，本页允许撤销一次；继续写入后该旧快照会清除，关闭页面后也不能撤销。已下载、打印或交给他人的旧文件无法追回；撤回只影响当前活动和此后生成的文件，旧副本需持有人自行删除。

本机文件与浏览器缓存没有加密或身份权限隔离；同一电脑的其他使用者可能看到。若需要彻底移除，先按需导出，然后使用产品清空活动并删除不应保留的备份和打印件。不要把本地保存当作永久档案。

## 检查和来源

开发检查在本目录执行，不需要 Auto Company 运行环境。全部输入采用虚构人物和事件。

```sh
npm ci
npx playwright install chromium
npm test
npm run test:browser
```

`npm test` 检查核心流程与恢复隐私；浏览器检查会自行启动本机页面，覆盖下载、打印内容、回应草稿、恢复、撤回、键盘确认及手机布局。可用 `FAMILY_MEMORY_BROWSER` 指定已有 Chromium。详细说明见 [docs/TESTING.md](docs/TESTING.md)。

破坏性操作、导出隐私提示及修改称呼使用页内对话框；Escape 和取消保留当前数据，焦点回到原操作。清空、替换、恢复和导出仍要求明确确认。

本产品在历史原运行中接续 memory-weave-lab 先行实验的署名、分歧、补问和撤回经验，并依据其派生标题失败修复设计；该先行项目不在此独立副本中，旧实验源码、合同和历史证据未修改。完整产品使用原生HTML/CSS/JavaScript，无自动关联或付费模型调用。
