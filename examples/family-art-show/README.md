# 家里的小展会

孩子选作品、定顺序、自在主持的家庭小美术馆。无账号、无外部服务、无前端框架依赖；照片和文字只在当前浏览器处理。没有作品解释生成、评分或教育效果承诺。

## 打开

建议在本目录使用 Node.js 运行（不需要安装运行依赖）：

```sh
npm start
```

浏览器打开 <http://127.0.0.1:4188>。使用同一个地址与浏览器继续保存的小展会。`file://`、不同端口与不同浏览器可能使用不同的本机存储；建议常用固定的本地地址，并定期导出备份。

## 办一场小展会

1. 填展会名字和小主持昵称，均可留空。
2. 添加一件或多件作品：上传本地 PNG / JPEG / WebP，或只记录手边的原作。作品名字与孩子原话可以留白，原话不会被改写。
3. 默认作品暂不展示。问孩子是否愿意入展，再选择“这次展示”。在作品夹编辑、删除、上移、下移，排好顺序。
4. 开始小展会。逐件看，可以记录新的孩子原话，也可以不说、跳过、暂停或立即结束。暂停和未完成的原话会保存，刷新后点击“主持”继续。
5. 回顾保留每场当时的文字，不生成解释。修改图片不会改变历史回顾文字；当前图片与当前原话出现在展签中。以后撤回入展或删除作品，该作品也会从回顾和打印中隐藏。

在主持期间调整作品夹，会结束当前这一场，保留已记录的文字；重新开始使用新顺序。最多保留 20 场回顾，达到上限后先导出完整备份，再清空重新策展，旧记录仍在备份文件中。

## 图片、保存与恢复

- 最多 24 件作品；原始图片单张不超过 12 MB、3200 万像素。浏览器将完整图片缩小到最长边最多 1600 像素，压缩为 WebP（不支持时 PNG）。不裁剪构图，但压缩可能改变细节；请保留原作和原始照片。
- 单张存储图片不超过 24 万字符，整场数据不超过 240 万字符。接近容量时请备份，再减少图片。本机实际可用空间受浏览器限制。
- 自动保存成功与失败会显示明确状态。空间不足时当前页面仍保留新作品，立即导出备份；刷新或关闭可能丢失未保存改动。
- 损坏的本机记录不会被自动覆盖。可导入有效备份恢复，或确认清空后重新开始。无法访问存储时仍能在页面里准备作品并导出。
- “导出完整备份”下载 JSON，包含全部图片、原话、入展选择、顺序、主持进度和历史记录。“导入备份”先检查版本、结构、大小、文字、图片与记录关系，确认后才覆盖；校验或写入失败保留当前小展会。
- 备份文件必须大于 0 且不超过 5 MB。只支持此工具导出的版本 1 JSON。不要手动改结构。导出含完整私人数据，包含暂不展示作品和已删除作品的历史文字；分享前请自行检查内容。
- 删除、清空与示例加载都先确认。删除移除当前图片和展签，历史文字仍保留在本机私人记录中，导出备份时会包含；完整清空才移除全部历史。

## 打印 / 保存 PDF

回顾页点击“打印展签与回顾 / 存为 PDF”，在浏览器打印窗口选择打印机或“另存为 PDF”。打印稿包含主持说明、每件入展作品的完整图片与展签、历次可展示的回顾文字。图片保持比例、不裁剪；长文字自然跨页。没有入展作品时不会启动打印。

浏览器建议使用 A4、默认比例，关闭浏览器页眉页脚。无需打印机：直接在页面主持，或用原作与纸笔。实际打印分页和实体打印效果仍由浏览器与打印机决定。

## 演示与边界

初次打开为空展。“看看合成示例”可明确选择加载构造的示例，会先请求覆盖确认；所有示例都标明合成，不代表真实孩子、家庭体验或教育收益。此交付只包含本地软件，没有真实用户验证、交易、收费或发布。

开发验收命令、证据与交付范围见 [DELIVERY.md](./DELIVERY.md)。

## 开发检查

运行 `npm ci` 后，`npm test` 执行真实 Chromium 流程、输入恢复与可访问布局检查。首次测试请运行 `npx playwright install chromium`。测试会自行启动本地页面。
