# 交错岛 · 使用与交接

《交错岛》是一篇原创中文双人叙事体验。两位伙伴各自创造地标，先进入对方设定的环境，再揭晓缘由，最后共同决定留路、留物或停在这里。没有主持人、账户或联网服务。

## 打开与准备

直接用桌面浏览器打开本目录的 `index.html`，无需安装依赖。两人轮流操作同一设备；不提供远程房间或多设备同步。可用纸笔另画地标，浏览器保存外形的文字描述。

如希望通过本机 HTTP 打开，在本目录运行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8000`；用 Ctrl+C 停止。此命令只服务本地静态文件。直接打开文件与 HTTP 是两个存储位置，迁移时用进度 JSON 导出/导入。

## 完整体验

| 步骤 | 两人做什么 | 得到什么 |
|---|---|---|
| 分别创造 | 阿岚独自写名字、灯塔外形、虚构缘由、光照条件和预测，封存后把屏幕交给雨生；雨生同样创造花园和潮汐条件 | 两份保留原句的作品 |
| 进入对方世界 | 根据交接页轮流操作；先只看到对方环境条件，分别写自己的行动细节 | 每个人的条件都改变对方可行的行动 |
| 一起揭晓 | 双方到场，一起读外形、缘由、预测和行动 | 可以比较原先想象和真实写下的回应；没有猜中计分 |
| 共同取舍 | 两人分别选择，写下共同结局；可以留下反思 | 同意留路或留物才完成；分歧保持未结束，也可停止 |
| 保留作品 | 下载 Markdown 纪念记录，或打印/保存为 PDF；同时可保存 JSON 进度 | 可离线阅读的原句、条件、行动、取舍与回望 |

光照的月光/日光与潮汐的退潮/涨潮产生四种路线。留路花两枚筹码、失去原物外形并留下离岛路；留物各花一枚、原物完整但放弃离岛路；停下不花筹码、保留已有作品且没有共同结局。名字、外形和缘由参与人的理解与讲述；程序不自动分析任意句子的意义。

## 纸面方式

打开 `printable.html` 或点页面上的“纸面体验包”。这是完整的 5 页包：共同说明、两张独立角色卡、交叉规则/取舍页、纪念页。建议 A4、原比例、关闭浏览器页眉页脚，用打印功能保存 PDF 或自行打印。两枚筹码可剪下，也可用硬币或画的圆代替。遮盖角色卡上的创作区，依照纸面规则完成全部体验，不依赖浏览器输入。实际打印效果取决于字体和打印设置。

## 保存、暂停与恢复

- 写字和选择会保存草稿到当前浏览器的本地存储；刷新后恢复当前阶段。若存储不可用，页脚会说明，当前窗口仍可使用，请下载进度。
- “暂停”盖住作品；“准备好了，继续旅程”恢复原阶段。暂停适合稍后继续；“停在这里”经确认后结束当前体验，保留已有输入，可导出，但不能在这一局继续作出共同结局。
- “保存进度”下载 JSON，包含双方全部已写原句，包括封存内容。用“导入进度”选择本产品导出的文件，验证成功后还需确认替换；取消不会覆盖当前作品。损坏、超大、未知版本和阶段不一致的文件会被拒绝。
- “另起一局”会确认替换本机进度。请先下载备份。清除浏览器数据、切换浏览器、设备或打开方式会失去对应本地存档；下载文件不受影响。
- 同一设备的多标签页不会同步，请只用一个标签页操作。封存是共同约定的屏幕遮盖，不是加密或访问控制；备份及本地存档包含双方文字。

## 检查与维护

本副本提供 Node 规则检查与 Chromium 浏览器检查，覆盖四环境、三结局、顺序、分歧、退出、输入限制、备份往返与恢复，以及桌面/手机核心流程、下载与纸面分页。测试使用构造输入，不代表真人体验。

从本产品目录执行：

```sh
npm ci
npx playwright install chromium
npm run test:engine
npm run test:browser
```

产品无需这些开发依赖即可使用。检查输出位于 `.auto-company`。原实验 `cards/`、`sample.json`、`experiment.py` 保留；实际浏览器入口为 `index.html`。
