# 交错岛 · 共同规则

你们来到一座潮汐小岛。它不是真实的往事，而是今天一起创造的世界。阿岚带来纸灯塔，雨生带来玻璃花园。今晚只能留下一条离岛通路，或留住这两件原物；不能两全。

准备两张纸、一支笔、两枚修复筹码（硬币、纸片或画的圆）。分别看自己的角色卡，先盖住图与句子。任何时候可以停，已有作品各自保留。

## 一：分别创造

各画地标，可以改名；写一句虚构缘由“我希望留住它，因为……”。不需真实回忆，不评价好坏。阿岚选灯塔只在月光或日光照路；雨生选花园只在退潮或涨潮开放。各写“我猜对方会……”并封存。

名字和自由句用于意义与讲述；环境规则决定可行行动。本版本不会自动解读任意句子来改剧情。

## 二：进入对方世界，再揭晓

仅交换环境规则，继续盖住图、缘由和预测。

| 对方的条件 | 你必须面对的行动 |
|---|---|
| 花园在退潮开放 | 阿岚踏浅滩送灯塔，不能使用浮台 |
| 花园在涨潮开放 | 阿岚搭潮汐浮台送灯塔，不能走浅滩 |
| 灯塔在月光照路 | 雨生夜间递灯，不能使用晨间反光 |
| 灯塔在日光照路 | 雨生晨间反光，不能使用夜间递灯 |

各说一句“在你的世界里，我打算……”，允许加虚构细节，不需猜正确答案。一起揭开图、缘由和预测，标记与预测不同处。没有对错计分，也不要求发生惊喜。

## 三：共同取舍

岛只剩两枚筹码的修复能力。读完两个缘由，共同选一种；无法同意就停，不强迫对方接受结局。

| 选择 | 筹码与地图改动 | 得到／放弃 |
|---|---|---|
| 留路 | 两枚修路。灯塔拆成路灯，花园拆成路面或浮台材料。划掉两件原物外形，保留名字与缘由，画出由光照和潮汐决定的通路 | 得共同航图，失原物；写“我们把……变成……，为了……” |
| 留物 | 各用一枚修原物，圈起两幅地标图，划去候选通路 | 得原物，失离岛路；写“我们留下……，愿意放弃……” |
| 停在这里 | 不用筹码，不画共同路线 | 留两张独立图、缘由和未同意的选择，注明没有共同结局 |

各补一句“我原以为……，但你让我看到……”，可以留空。保留双方原句、环境规则、行动、取舍与图。自由表达的意义需要真人判断；规则回放只检查环境选择的影响。
