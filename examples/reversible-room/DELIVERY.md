# 栖改 · 本地交付与操作说明

栖改帮助租客把一个房间的可逆改善计划落实为可核算、可验证和可带走的档案。适用范围是已有物品调整、风扇、独立遮帘、窗缝密封、玻璃膜、定制内窗的规划比较；具体设备与施工必须另行核实。软件无需账户和联网服务，不执行采购、安装或现实联络。

## 启动与停止

需要 Python 3 和支持现代 JavaScript 的浏览器。在产品目录执行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 http://127.0.0.1:8765 。保持终端运行；`Ctrl+C` 停止。端口被占用时改为8766，并打开对应地址。不要直接双击HTML；本机HTTP用于加载模块。没有配置系统服务，没有公开发布或部署。

## 完整使用流程

| 步骤 | 操作与得到的结果 |
|---|---|
| 1 房间档案 | 填名称、目标、窗口尺寸与窗型、租约权限、表面和玻璃状态、逃生/通风、风险、预算、使用与搬迁成本条件。点击“生成适配方案”。示例为构造档案，不自动产生实测记录。 |
| 2 方案与成本 | 比较六个候选与不采购路径。查看可试用、待核实或排除原因；只有可试用方案能采用。费用包含税运、工具/安装时间、能耗、返工恢复和搬迁。按当地含税报价修改六项费用，超预算会撤销采用状态。 |
| 2 安装与回退 | 采用后查看实施、回退和现场检查表。勾选仅表示使用者已核对，不代表专业批准。档案修改会清空旧核对结果，要求重新核实。 |
| 3 试验记录 | 记录改善前后时间、空气温湿度、体感、室外温度、可选辐射温度与备注。至少前后各两次；条件不可比则不输出可归因结论。观察变差时停止并恢复原状。 |
| 4 搬迁与交接 | 输入新房尺寸、权限、表面、窗型和现场条件，重新核对。旧档案和日记不覆盖；新房默认未确认，费用重新估算。补充材料型号、当地报价与未核实事项。 |
| 4 导出与恢复 | 导出Markdown交接单、打印交接单，或导出完整JSON备份。恢复备份会校验版本、字段、费用、记录和大小；坏文件不会覆盖当前档案。 |

## 数据保存与恢复

档案保存在当前浏览器、当前地址的本地存储中，不上传服务器。不同端口、浏览器或设备的数据互不相通；隐私模式、清除浏览器数据和存储不可用可能导致丢失。请定期导出JSON备份；Markdown是可阅读交接单，不能作为完整恢复文件。

存储失败会显示提示，当前内存中仍可继续操作并导出，刷新可能丢失。清空需要原生确认；取消保留当前数据。确认清空后只有有效备份可恢复。备份最多1MB、日记最多500条，备注与各字段有长度/范围限制。输入HTML会按文字显示，不执行。

旧房记录会保留；新房再适配是独立的规划记录。原房间尺寸或权限变更后不会将旧检查表当作新条件已核实。新房玻璃兼容始终默认未知，不能继承旧房安装批准。

## 判断边界与失败恢复

| 情况 | 处理方式 |
|---|---|
| 湿损、霉斑、电气异常、持续过热/不适 | 暂停相关设备和窗体施工，先记录与处理风险。软件不能诊断热健康、维修电路或处理霉菌。 |
| 逃生或通风需保留 | 不封死开启/通行；未核实现场时窗体施工待核实或排除。密封须不影响燃烧设备通风。 |
| 玻璃/膜兼容未知 | 不放行窗膜；玻璃类型已知仍需要厂商兼容和保修说明。 |
| 零孔或胶粘权限限制、表面脆弱 | 排除相应固定方式；优先已有物品或独立设备。可拆不保证无损。 |
| 超预算、费用未知 | 修改假设或选择不采购路径；预算状态不是报价保证。缺报价保留估算标记，不把未知填零。 |
| 观察不充分或天气不同 | 显示不足/不可比；即使条件相近，前后差也不能证明因果。日记可保留恶化及无变化。 |
| 搬迁尺寸不符 | 定制/裁剪材料可能需更换；再次核实固定、开启、许可和配件，不能保证重复适配。 |
| 输入错误、损坏备份 | 按错误提示修正；拒绝恢复且不破坏当前档案。 |

## 检查与证据

历史原运行由框架工具登记验收，其私有记录不随此独立副本公开。独立开发检查使用 Node 原生测试和 Playwright 浏览器流程。操作、日期、费用、记录、备份、权限、搬迁、移动和键盘场景使用构造输入，不代表真人试用。

浏览器测试依赖仅用于检查；产品本身没有运行依赖。在本目录执行 `npm ci`、`npx playwright install chromium`、`npm test`、`npm run test:browser`；复现说明见 [tests/README.md](tests/README.md)。原运行结果与回执留在历史运行，本文件不手工制造测试数或验收成功。

公开依据与费用口径见 [SOURCE.md](SOURCE.md)。历史独立风险审查、原机会评估和失败工件保持原样，未随独立副本公开。

没有实际房间效果、物理安装、实际搬迁、厂商现场适配批准、真实用户采用、成交或盈利证据。当前交付是完整可操作的本地软件；不提供实际履约、医疗/消防/建筑安全认证或实时采购推荐。没有注册、外联、收费、发布、推送或部署。
