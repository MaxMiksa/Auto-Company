# 依据、规则与费用假设

本工具以“先比较已有物品、明确适配条件、小步观察、可恢复交接”为流程。规则为产品的保守筛选设计，不是专业安装批准。没有接入商品库存、报价、热舒适计算或支付服务。

| 公开资料 | 本产品采用的边界 |

## 成本含义

所有金额用人民币，仅为可修改的规划假设。没有汇率换算或抓取现价，也没有进行采购。初始材料成本是该类方案的构造估算，不是品牌产品报价。

| 类别 | 应填内容 |
|---|---|
| 材料与税费 | 本次新增物品、消耗材料及税费；已有物品不重复计购买价。 |
| 配送与税运 | 配送、跨境或地方税运；请避免与材料项重复计算。 |
| 工具与安装 | 工具、测量、安装、支持的现金支出及人工机会成本。 |
| 使用能耗 | 默认按功率÷1000×每日小时×使用天数×电价计算；可按实际账单修改。 |
| 返工与恢复 | 拆除恢复、清洁、退换/裁剪损耗、支持和预留。 |
| 搬迁适配 | 每次搬迁重测、配件、更换损耗与工时；不保证可重复移装。 |

总计始终为六项之和，人工机会成本不代表已支付现金。修改字段必须完整填写非负金额，真实未知时不要虚填0；保留默认估算并在备注标明待报价。预算状态仅针对当前估算，不是完整实时报价证明。

观察摘要中的“条件相近”仅采用全部外温记录跨度不超过2℃这一产品启发式条件，不是行业标准或实验因果控制。日期、湿度、辐射、日照和设备状态仍须自行比较；当前热体感评分不能直接判断眩光改善，应在备注记录对应任务与光照变化。

没有真实客户、收入、订单、安装、真实房间试验或实际搬迁观察。原成功与失败实验保持在历史评估目录，不复制成当前产品的真人记录。
