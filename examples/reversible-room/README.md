# 栖改 · 租客舒适工作台

一个无需账户的中文本地工具：从房间与窗户档案，完成可逆改善方案筛选、完整费用比较、安装与回退检查、前后观察、搬迁再适配和可恢复交接。

在本目录执行：

```sh
python -m http.server 8765 --bind 127.0.0.1
```

浏览器打开 http://127.0.0.1:8765 。不要直接双击 `index.html`；模块需要本机 HTTP 服务。`Ctrl+C` 停止服务。

完整使用方法、风险与数据恢复见 [DELIVERY.md](DELIVERY.md)。公开依据和费用假设见 [SOURCE.md](SOURCE.md)。

本地软件交付不代表物理安装、实际温降、真人采用、成交或盈利。

Windows 使用 `python`；macOS / Linux 使用 `python3`。也可在产品目录执行 `npm start`。
