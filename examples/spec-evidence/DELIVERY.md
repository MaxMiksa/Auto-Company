# 规格证据台：交接与操作说明

这是可在本地浏览器使用的工程采购规格变更证据核验工作台，资料在本机处理。使用者整理证据，工程负责人复核，工具不代替选料、采购审批或专业等价判断。所有内置采购案例都是构造资料，不是真实客户或交易。

## 启动

需要 Node.js 22 或更新版本和现代浏览器；使用功能不需安装开发依赖。

```sh
npm start
```

在浏览器打开 `http://127.0.0.1:8080`。若端口占用，在本产品目录执行 `node serve.cjs 8081` 并打开相应地址。按 Ctrl+C 停止。

## 完整任务

1. 在工作台载入示例了解格式，或上传、粘贴自己的旧规格、新规格、需求CSV。为当前资料包填写名称。
2. 对每个参数填写准确料号、参数类型、数值、单位、文档修订、来源、原文位置和摘录。需求指定min（至少）、max（至多）或equals（相等）。
3. 执行核验。查看阻断、待复核及未发现差异；点击结果查看旧新证据和原因。
4. 如有需要，附上本机PDF或TXT原件以便对照。PDF附件是供人查看的原件，不会自动提取或理解全部规格。
5. 为需处理的条目填写复核人、决定与意见。原始机器发现与人工决定并存；记录接受不会删除数值不满足或资料不足。
6. 下载CSV交接表或可打印报告；保存项目JSON备份。需要继续工作时导入备份，核验结果由输入重算。

## 输入约定

UTF-8 CSV，首行是列名，包含逗号、双引号或换行的字段必须按标准CSV加双引号，字段内部双引号写为两个双引号。可下载或参考 `samples/` 中三个构造示例。

| 表 | 列 | 含义 |
|---|---|---|
| 旧、新规格 | mpn,parameter,value,unit,revision,source,locator,quote | 料号、参数、数值或文字、单位、修订、文档来源、页码/章节/行号、原文摘录 |
| 需求 | mpn,parameter,operator,value,unit | 料号、参数、min/max/equals、要求值、单位 |

按料号和参数精确对应；同一料号的不同条件必须用不同parameter表达，例如“供电绝对最大值”和“供电推荐上限”，不能都写“电压”。参数名称不同会视为不同项，工具不会推断两者等价。不同料号新增和移除分别显示，不自动认定替代料可用。

支持明确的压力（Pa/kPa/MPa/bar）、电压（V/mV）、电流（A/mA）、频率（Hz/kHz/MHz）及摄氏温度（°C/C）单位换算。其他单位保持待复核，不自动猜测。数值输入用小数点，可用科学计数法；范围、±表达及条件句需提取成明确字段，保留原文，不以单一数字代表全部工程意义。缺值、缺资料及冲突不能自动判为合格。

`source`记录文件名、文档号或公开地址；`locator`记录确切位置；`quote`保留原文。系统核验这些字段是否具备，不声称已独立证明原文真实、来源权威或提取准确。即使有原件附件，仍需人工对照。

## 复核和恢复

页面尝试在当前浏览器的本地存储保存工作；浏览器拒绝、容量不足或隐私模式可能导致保存失败，界面会提示。请在重要节点下载项目JSON，不以浏览器缓存为唯一备份。清除站点数据、换浏览器或换端口可能无法看到原保存，使用JSON导入恢复。

输入变化后需要重新核验并重新复核，避免对新资料沿用旧结论。无效CSV或损坏JSON应显示错误并保留可恢复的原工作。对大文件可拆成多个有名称的资料包；浏览器原件附件总量限制10MB，格式为PDF或TXT。超过限制时保留原文件在本机，CSV的source/locator仍可追溯，不必把所有原件装进项目。

导出的CSV对危险公式前缀作文本保护；HTML报告对输入转义。报告和JSON包含你导入的资料与意见，交接前按自己的组织要求检查内容与权限。工具不发送资料、不托管文件，没有多人协同或中央版本库。

## 实际检查与维护

核心使用Node原生测试，浏览器使用Playwright。安装测试依赖仅用于开发：

```sh
npm ci
npm test
```

首次浏览器测试先执行 `npx playwright install chromium`，再执行下列命令，测试自动启动本机服务。已有浏览器可设置 `CHROMIUM_EXECUTABLE_PATH`，已有产品服务可设置 `PRODUCT_URL`。

```sh
npm run test:browser
```

原模型运行的程序验收与交付合同状态保持在原运行中，本展示副本不包含私密历史。浏览器测试输出默认位于 `test-results/`，可用 `PLAYWRIGHT_OUTPUT_DIR` 指定证据位置。不把此说明本身当作测试通过证据。

## 剩余边界

不支持任意PDF自动抽取、扫描OCR、自动抓取PCN、专业等价批准、供应商系统集成或采购交易。数据来源和工程意义由使用者确认。真实历史证据中TI文档存在绝对最大与推荐条件、旧修订依据及内部表述不一致等限制，NXP更正也不能自动视为功能改变；原评估保存在历史运行，未被本产品改写，也不包含在此独立副本中。

本地功能可交付与商业成立是不同结论。普通人工表格、现有完整PCN系统仍是强替代；没有测得实际买方节时、真实采用、付款或盈利。用户0，收入$0。本轮没有外联、注册、收费、部署或发布。
