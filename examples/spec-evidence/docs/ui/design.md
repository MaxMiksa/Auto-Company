# 规格证据台界面与交互

已按 ui-duarte、interaction-cooper 角色与 frontend-design 技能实施。主要使用场景是工程采购人员在签核前对照已提取的新旧规格行，定位原文，留存自己的处理意见；此场景是设计假设，未声称经过真实用户验证。

| 决策 | 实现 |
| --- | --- |
| 工业文档工作台 | 左侧编号步骤，右侧三份输入、宽对照表、成对原文与复核表单；入口直接工作 |
| 排版 | 中文本机宋体用于主标题与原文，中文无衬线用于操作；本机等宽字体用于 CSV、编号、摘要；不请求外部字体 |
| 色彩语义 | 暖纸 #f5f2e9；主操作深墨绿 #173d34；待复核琥珀 #a9650c；阻断红 #a33025；清晰项绿色 |
| 风险独立 | 机器阻断、机器待复核、未人工复核单独计数；人工接受不会使风险消失 |
| 恢复 | 每次修改尝试本机保存；失败明确提示下载备份；项目备份先校验再替换当前项目 |
| 变更失效 | 任一输入编辑立即清空旧结果与复核、禁用结果导出；重新核验后才可导出 |
| 原件 | PDF/TXT 仅留存、计算摘要与本机预览；不宣称自动读 PDF；备份总大小限制 10 MB |
| 无障碍 | 表单 label、跳过导航、明显焦点、机器结论文字、aria-live 状态、筛选 aria-pressed、原生 dialog |
| 移动端 | 760 px 以下侧栏变为顶部步骤，输入与原文单列；宽对照表仅在自身容器横向滚动 |

核心流程：载入示例或提供三份 CSV → 执行核验 → 选择条目查看原文位置 → 填写姓名及处理意见 → 保存复核 → 下载 CSV / 打印报告 / 下载完整项目备份。清空有单独确认，CSV 与备份错误不会清除原输入。示例是合成数据，仅说明核验机制。

本机存储与导出的项目可能含采购资料。原件只在当前浏览器中使用，恢复备份不会执行其中的 HTML 或脚本；任何动态原文均通过文本节点展示。此界面没有注册、支付、外联或发布入口。
