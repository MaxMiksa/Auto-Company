# 图证工作台交接

这是一个在本地浏览器使用的图表资料制作工作台：将长表 CSV 整理成带来源、坐标轴、缺测/近似等语义和人工复核记录的资料，再导出给读者。所有操作在浏览器内进行，不需要账户或外部服务。

## 打开工作台

在产品目录运行：

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

浏览器打开 `http://localhost:8080`。结束时在启动终端按 `Ctrl+C`。也可直接用浏览器打开 `index.html`；如浏览器限制文件页面的本地存储或下载，请改用上述本地服务。

浏览器草稿按来源分别存放：直接打开文件、`localhost:8080` 与 `127.0.0.1:8080` 不共享草稿。清除浏览器站点数据、隐私模式或更换浏览器可能使草稿不可用；重要资料应另存 JSON 备份。

## 完成一份资料

1. 使用“载入构造样例”了解语义，或“下载输入模板”整理自己的数据。
2. 粘贴 CSV 后点击“导入 CSV”，或用“选择 CSV 文件”直接导入文件。检查系列、坐标和每点语义；填写标题、原始来源、横纵轴名称/单位及线性或对数类型，再点击“保存来源说明”。保存前这些输入是来源草稿，切换系列、筛选待复核、编辑单点或署名不会清空它们。CSV 导入替换整份项目，不沿用原项目的来源与复核记录；继续原工作前先保存来源说明并备份 JSON。
3. 对照原表或原图逐点编辑与核对。缺测保持空数值；近似、插值和未确认需明确标注。记录证据位置与必要说明。
4. 填写人工复核责任信息，核对各点。更改数据、语义、证据、来源或轴说明后重新复核失效记录。
5. 查看中文非视觉阅读区，确认读者可知道各系列数值、单位、缺测、近似以及复核限制。
6. 点击“备份项目 JSON”，导出阅读资料 HTML、CSV 或 Markdown 供交接。读取导出文件确认来源、语义与复核状态仍在。继续编辑时用“恢复项目 JSON 备份”。

## 文件用途

| 文件 | 适合用途 | 不能替代 |
|---|---|---|
| CSV 输入/导出 | 长表数据交换、保留逐点语义 | 完整来源/轴/责任资料或可编辑项目备份；交付时搭配 HTML 或 JSON |
| JSON 备份 | 保存并恢复工作台资料、复核及审计 | 可信身份签名或真实性证明 |
| 独立 HTML | 离线打开阅读资料，无需工作台 | 专业读屏实测或合规认证 |
| Markdown | 文字交接、资料归档 | 交互式编辑 |

CSV 列说明与格式示例见 [README.md](README.md)。Markdown 的文字说明应保留；CSV 需要配套完整资料。不要仅抽出数字交接，否则会丢失来源、缺测与复核含义。JSON 项目结构的版本为 `1`，使用工作台生成的完整备份恢复，不手工裁剪字段。

## 来源草稿与已保存资料

标题、来源、两轴名称、两轴尺度及背景说明在点击“保存来源说明”前属于独立草稿。来源区会标明状态；浏览器允许存储时，刷新恢复已保存资料和未保存来源草稿。筛选、单点保存与署名复核基于已保存资料，草稿不会自动改变阅读结果或撤销复核。

| 操作 | 对来源草稿的处理 |
|---|---|
| 切换筛选、编辑点值、署名复核 | 保留草稿，阅读资料仍使用已保存说明 |
| 保存来源说明成功 | 将草稿写入资料；说明有变更时撤销旧复核 |
| 保存校验失败 | 保留草稿和原资料，按错误提示更正后重试 |
| 导出 HTML、Markdown、CSV、JSON | 只导出已保存资料；未保存来源草稿不在文件中 |
| 放弃来源草稿 | 确认后恢复已保存说明，原资料及其复核不变 |
| 替换项目或清空 | 确认后丢弃草稿；取消则保留当前资料和草稿 |

交付或跨浏览器继续前，先保存来源说明、重新核对失效的复核，再下载 JSON 或阅读资料。仅下载 JSON 无法备份未保存来源草稿；若浏览器存储失败且暂时无法保存说明，请另行复制草稿文字保留。

## 出错与恢复

导入错误按提示修正原文件后重试，失败时当前工作应保留。对数轴只接受正坐标；应核对轴型而不是人为更改数值使其通过。浏览器存储失败时立即下载 JSON 备份；恢复备份前确认文件来自可信来源并备份当前工作，成功恢复会替换整份项目。复核失效表示相关资料发生了改变，需要再次人工核对，不能通过重命名复核者绕过。

## 证据与适用边界

工作台不会自动从截图识别数值，也不会证明来源、轴配置或数字的真实性。可先从原表或 WebPlotDigitizer 等工具整理 CSV，再人工复核。像素附近存在标记不代表轴尺度正确。

示例是构造素材，不是真实用户、采用或商业验证。没有专业读屏实测；语义表格、键盘路径与非视觉中文阅读区用于支持阅读，不能作为无障碍合规认证。填写的复核者姓名是资料声明，不是登录身份验证、电子签名或独立审计。资料提供者负责来源使用权、事实核对和专业用途判断。

实际功能检查与正式交付状态以框架生成的检查/交付记录为准；本文件不自行宣称检查通过。
