# 图证工作台

本地制作可核验的非视觉图表资料：导入整理后的长表 CSV，注明坐标轴和来源，保留每点的缺测、近似、插值与未确认状态，完成可追踪的人工复核，再导出独立阅读资料。

## 本地打开

安装 Node.js 22 或更新版本，在本目录运行（Windows、macOS、Linux 均可）：

```sh
npm start
```

用浏览器访问 `http://localhost:8080`，结束时在终端按 `Ctrl+C`。也可直接打开 `index.html`；浏览器对文件页面的存储/下载策略可能不同。无需安装应用依赖、注册或登录。

完整操作和责任边界见 [DELIVERY.md](DELIVERY.md)。

开发检查：`npm ci`、`npx playwright install chromium`、`npm test`、`npm run test:browser`。浏览器测试自动启动本机服务，不依赖原运行的临时浏览器路径；`PRODUCT_URL` 可指定现有服务。

## CSV 长表

一行代表某个系列在某个横坐标的一点。前三列必需，后三列可选；推荐使用完整表头并显式填写语义：

```csv
series,x,y,kind,evidence,note
```

| 列 | 含义 | 填写要求 |
|---|---|---|
| `series` | 系列名称 | 使用可区分的中文或其他名称 |
| `x` | 横坐标 | 有限数值；对数轴必须为正 |
| `y` | 纵坐标 | 非缺测点为有限数值；缺测留空；对数轴非缺测值必须为正 |
| `kind` | 数值语义 | `observed` 观测、`approximate` 近似、`interpolated` 插值、`missing` 缺测、`unconfirmed` 未确认；有数值但省略时为未确认，空数值省略时为缺测 |
| `evidence` | 核对依据 | 写明原始表行、图中区域或公开来源位置；链接不自动证明正确 |
| `note` | 必要说明 | 如近似精度、插值办法、缺测原因与未确认问题 |

含逗号、双引号或换行的字段遵循 CSV 引号规则；字段内双引号写为两个双引号。建议使用 UTF-8。最多导入 5,000 点；横坐标必须为数值，日期可先整理为年份或时间编号。支持中文表头，但直接使用下载模板更容易避免列名错误。同一系列同一横坐标不可重复；缺测必须保留其行及空 `y`，不要省略后假定接收端知道缺口。

```csv
series,x,y,kind,evidence,note
样本A,2023,12,observed,原表第2行,
样本A,2024,,missing,原表第3行,未采集
样本A,2025,17.5,approximate,原图右侧标记,从图中读取的近似值
样本B,2023,11,unconfirmed,尚未找到原表,需补核对
```

可在界面的“下载输入模板”取得 [examples/template.csv](examples/template.csv)。以上为构造格式示例，不是实际测量数据。

粘贴后点击“导入 CSV”，或选择 CSV 文件直接导入。导入会替换整份项目，需重新填写来源说明，避免给新数据沿用旧来源与复核责任。继续现有资料前先备份 JSON；需要修改现有纵坐标、语义、证据或备注时使用逐点编辑。CSV 没有项目的完整元数据和审计，不能用来恢复完整项目；输入中的旧复核也会撤销，完整恢复请用 JSON。

标题、来源、轴名/单位、轴型和复核责任信息在工作台中补全。输入表格与资料说明共同构成可解释结果，单独一列数字无法交接缺测或真实性边界。

## 保存与导出

- 浏览器草稿保存当前资料与未保存来源输入；它受浏览器来源和存储设置限制，不是永久备份。筛选、单点编辑和署名复核保留全部来源草稿，刷新可恢复。
- 标题、来源、轴说明与背景输入须点击“保存来源说明”才进入资料，说明有变更时撤销旧复核。保存失败保留输入；“放弃来源草稿”确认后恢复已保存说明。
- “备份项目 JSON”保存可恢复工作台内容及责任记录；“恢复项目 JSON 备份”用于跨浏览器/来源恢复。先备份再清除站点数据。
- HTML 用于独立阅读，Markdown 用于文字交接。CSV 用于逐点数据交换，应搭配 HTML 或 JSON 交付，不能单独代替完整来源、轴说明与责任资料。
- 资料改动会使相关复核失效。导出中的“已复核”表示人工声明，不表示系统认证数据真实。

阅读区和 HTML、Markdown、CSV、JSON 文件均以已保存资料为准，未保存来源草稿不包含在导出中。交付和跨浏览器备份前先保存来源说明，再重新复核与导出。浏览器存储失败时，无法保存的来源草稿需另行复制保留。

`file://`、`http://localhost:8080` 与 `http://127.0.0.1:8080` 的草稿不共享。浏览器隐私模式、存储禁用和清除数据都可能使草稿消失。

JSON 使用版本 `1` 的项目结构，由工作台生成和恢复；保留完整文件，不自行删除字段或手工更改版本。它包括资料说明、数据语义与复核/审计信息，不是通用数字列表格式。

## 已知边界

不自动从截图提取数据，不验证来源身份、版权、轴配置或数值真实性。构造示例不是真实采用或商业证据；没有专业读屏实测，不宣称无障碍合规认证。使用者需对原始材料、人工核对与适用性负责。
