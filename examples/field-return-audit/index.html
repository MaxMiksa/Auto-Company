高级配置：业务表、关联、附件列

留空业务表清单时自动发现有主键的业务表；无主键表需要显式指定稳定键。关联和附件列应按业务含义声明，工具无法自动推断完整规则。

例如：observations 的唯一键为 uid，site_uid 指向 sites.uid，photo 保存如 photos/001.jpg 的相对路径。

{
  "tables": [
    {"name": "sites", "key": ["uid"]},
    {"name": "observations", "key": ["uid"]}
  ],
  "relations": [{
    "table": "observations", "column": "site_uid",
    "parent_table": "sites", "parent_column": "uid"
  }],
  "attachment_columns": [
    {"table": "observations", "column": "photo"}
  ]
}

数据与附件合计上限 100 MB。文件仅发送到本机服务。
