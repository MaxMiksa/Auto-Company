# 归档验收台

在本机浏览器核对离线采集的往返结果：出发基线 → 现场副本 → 回传主库。支持真实 SQLite/GeoPackage 文件及关联附件，导出中文 JSON、CSV 和独立 HTML 验收报告。

## 启动

需要 Python 3.10 或更新版本，日常使用不需要安装额外 Python 库。

```sh
python server.py --port 8765
```

在本目录运行，打开 `http://127.0.0.1:8765`。在终端按 `Ctrl+C` 停止。首次使用点击“载入合成示例”体验完整流程，再准备自己的文件。示例是构造数据，不是真实项目或客户证据。macOS/Linux 可将 `python` 换成 `python3`。

完整文件准备、配置、恢复与交接见 [DELIVERY.md](DELIVERY.md)。

## 范围

- 核查现场新增、修改和删除是否到达指定目标；允许无关办公室字段修改。
- 检查数据库完整性、关联与附件路径/内容。
- 保留 SQLite 正负 64 位整数的精确值与类型，记录键与三种导出均可追溯。
- 区分完整通过、待复核、按策略待补与证据不足未确认。
- 只读处理上传副本，不执行同步、合并或修复原库。

报告只证明上传证据之间的对应关系，不证明现场事实或所有设备已交齐，不判断几何的空间语义，也不证明真实用户采用或商业收益。
