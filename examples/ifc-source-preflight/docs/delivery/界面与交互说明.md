# 量源复核工作台

面向需要解释 IFC 版本数量变化的造价与 BIM 复核人员。用户先选择基准与当前 IFC，确认构件范围和体积字段，运行来源复核，再从问题清单定位对象，核对材料小计和完整差量，导出全部底稿。用户画像只是本次产品任务定位，没有据此宣称真实用户采用。

视觉以工程档案为隐喻：左侧墨绿输入区固定版本与范围，右侧纸白底稿呈现问题、材料、对象身份与完整来源。铜色只强调待复核内容和流程编号。标题采用本机中文衬线字体，正文采用本机中文无衬线字体，数字保持表格对齐，不调用外部字体、图片或服务。

| 状态 | 用户可见行为 |
|---|---|
| 初次进入 | 给出任务与复核边界；没有硬编码分析结果；可选择真实文件或载入合成 IFC |
| 两版就绪 | 启用“开始来源复核”；输入文件名持续可见 |
| 解析中 | 中文进度反馈；禁用文件、范围、样例及清空操作，避免同轮结果串线 |
| 结果完成 | 摘要、问题定位、材料小计、对象身份对应与来源筛选；CSV/JSON 均导出全部底稿 |
| 输入变化 | 旧结果立即失效，提示重新复核 |
| 文件或解析失败 | 中文原因与恢复提示；有效输入保留，可更换文件重试 |
| 清空 | 清除内存中的输入与结果，重置筛选并回到文件选择 |

窄屏按“输入 → 复核底稿”重排；宽表在自身容器内横向滚动，不扩大整页宽度。所有文件选择、范围、筛选和操作均有标签；按钮、文件框与输入有键盘焦点样式；结果状态使用实时提示。减少动态效果偏好会关闭过渡。用户文本通过 `textContent` 显示；CSV 文本会转义引号，并对公式前缀加单引号。

标识使用两叠来源页和对齐缺口，输入文件为 `icon.svg`，界面标识及 favicon 指向程序生成的 `/auto-company-icon.svg`。缺少产品 Logo brief，未访问其他项目资源。

自动化入口：`#old-file`、`#new-file`、`#demo-case`、`#load-demo`、`#element-type`、`#quantity-name`、`#analyze-button`、`#feedback`、`#results-content`、`#filter-version`、`#filter-issue`、`#source-search`、`#clear-filters`、`#export-csv`、`#export-json`、`#reset-button`。来源行带 `data-version`、`data-guid`、`data-element`；问题按钮带 `data-version` 与 `data-guid`。
