# 量源复核 · 本地交接

量源复核为中文造价/BIM复核人员提供双版本 IFC 数量来源检查。浏览器导入旧版和新版，检查模型声明体积的来源、单位和材料，定位缺失或冲突，再导出复核底稿。无账户，无云端上传；输入交由本机回环服务处理。

## 安装与启动

在本产品目录执行，需要 Python 3.10 或更新版本（本副本使用 Python 3.11 实测）。首次安装需要访问公开 Python 包仓库，安装完成后运行无需联网。

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python server.py --port 8765
```

浏览器打开 `http://127.0.0.1:8765`，保持启动终端运行。关闭服务按 `Ctrl+C`。端口被占用时改用 `--port 8766` 并打开对应地址。不要双击 `index.html`，页面需要本地解析服务。

Windows PowerShell 在本产品目录执行：

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
.venv/Scripts/python.exe server.py --port 8765
```

独立展示副本已在 Windows 原生 Python 与 Chrome 实测；服务仅绑定 `127.0.0.1`。

## 完整操作流程

1. 在左侧选择旧版和新版 `.ifc` 文件，也可加载明确标注为合成的示例。示例包含正常增量、换材、单位、缺数、来源冲突和身份重建等情况。
2. 选择构件类型与体积字段。默认检查 `IfcElement` 的 `NetVolume`；只检查墙可选 `IfcWall`。`GrossVolume` 与 `NetVolume` 是不同口径，不能相互替代。
3. 执行复核，先读完整性和问题提示，再看材料已知小计、来源明细和对象变化。搜索、版本及问题筛选用于定位底稿。
4. 导出来源 CSV 和完整 JSON。导出包含全量数据，不因屏幕筛选而丢失来源。JSON 保留输入文件名、SHA-256、schema、筛选口径、问题及比较；CSV 保留来源实体、原值、单位及材料等。
5. 对照原模型处理问题后，从建模工具重新导出 IFC，替换文件并再次复核。输入或口径变更后需要重新执行；清空可以开始新的版本对。

## 如何理解结果

| 结果 | 含义与使用方法 |
|---|---|
| 已知小计 | 仅包含能唯一解释、单位可换算的有效来源，不能代替完整总量 |
| 完整差量 | 只有相应范围来源完整时才提供；材料无法归因时材料完整差量留空 |
| 缺失数量 | 所选字段没有可信来源；不是零，不能直接解释为删除工程量 |
| 多来源或口径问题 | 保留每个来源，不自动选择先出现的值，也不将冲突值求和 |
| 未知单位 | 原值保留；修复项目/数量显式单位后重新导出，不猜测立方米 |
| 复杂或未知材料 | 原材料结构保留，不把层集/多材料任意归为一种材料 |
| 身份问题 | 同名、同量不是对象身份的证明；GUID 重建不推测对象一一匹配 |
| 总成与子件重叠 | 保留候选数量，小计可能含重复计量；完整差量留空，需确认汇总范围 |
| 计量依据或 schema 差异 | 保留两版原始来源与小计，确认口径一致后再决定是否可比 |

实体编号只在对应输入文件内有效，跨文件应结合文件哈希、版本与 GUID 查找。来源的 `scope` 用于区别构件与类型来源。CSV 对可能触发电子表格公式的文本加保护前缀；审计原始文本以 JSON 为准。界面中的字段与构件协议名保留 IFC 原名。

## 输入与恢复边界

- 支持 IFC2X3 和 IFC4 STEP 文本；目前不支持 IFC4X3、IFCZIP、IFCXML、任意二进制或压缩包。单文件限制 10 MiB，适合单专业/分区模型。
- 文本按严格 UTF-8（含 ASCII 与 UTF-8 BOM）读入；非 UTF-8 请重新导出为 UTF-8 或使用 IFC 标准文本转义。不会静默替换错误字符，输入哈希对应原 UTF-8 文件字节。
- 仅处理模型已有的体积数量字段；不计算几何体积、不审查采购损耗、不推导价格、碳排或结算量。
- 错误文件、空文件、无相应构件与超限输入会提示中文错误。确认导出为 IFC STEP、检查字段/构件筛选、缩小到分区导出后重新选择文件。
- 导出的空完整差量表示未解决，不能当作零。解决办法是回到来源模型确认单位、数量口径、材料或对象身份后重新导出；工具不替专业人员签核。
- 文件只经浏览器与本机服务内存处理，程序不保存上传模型。关闭页面会失去当前结果，应先下载底稿。浏览器下载文件由使用者自行管理。
- 真实项目导出器、多层复杂材料、超大模型及普通使用者准备时间尚未验证；合成示例不证明真实采用、节时或采购正确性。

## 检查与维护

在本目录运行 Python 核心与 HTTP 检查：Windows 使用 `.venv/Scripts/python.exe -m unittest discover -s tests -v`；macOS/Linux 使用 `.venv/bin/python -m unittest discover -s tests -v`。

浏览器检查安装开发依赖 `npm ci`，再安装测试浏览器 `npx playwright install chromium`，执行 `npm run test:browser`。默认自动启停本产品虚拟环境中的服务。可用 `IFC_PYTHON` 指定已有 Python 环境，用 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定已有 Chrome/Chromium；这两项不是日常使用前提。

检查覆盖真实 IFC 实体、来源、单位、材料、错误恢复、实际文件上传、筛选及 CSV/JSON 下载。独立展示副本不附带原运行的私有登记、模型日志或商业历史。页面截图不证明真实客户采用、业务收益或工程数量准确性。

`preview.cjs` 是可选预览入口，传入本机端口并先安装本产品 `.venv`；其子服务随预览进程关闭。
