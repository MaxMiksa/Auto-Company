# 触图审查台交接

本地产品的目标是保留SVG原始数据点与对象语义，让教师或图形制作者得到可解释、可恢复的打印前空间关系审查。它不认证规范合格，不代替实体试印或专业转写。

## 启动

在本产品目录执行 `python serve.py`，打开终端显示的 `http://127.0.0.1:8765/`。macOS/Linux 可将 `python` 换成 `python3`。Python 3标准库即可，不需要安装运行依赖。保持终端打开，Ctrl+C停止；端口占用用 `python serve.py --port 0`。界面需要现代支持SVG几何接口的浏览器；本次验证使用Chromium。浏览器本地处理文件，无登录、上传、网络API或外部字体请求。无需部署，file协议直接双击入口可能无法加载模块，请用HTTP入口。

## 完整操作

| 步骤 | 操作与结果 |
|---|---|
| 输入 | 上传SVG、粘贴原文，或选择内置标签/TVL练习材料；出错会显示原因 |
| 尺度 | 明确mm/cm/in尺寸可建立毫米映射；无单位或px图需填写实际打印宽高并确认，不能用像素代替物理测量 |
| 审查 | 查看对象名称、毫米边界和关系；近距阈值是可调整的作者策略，不是BANA合格阈值 |
| 判定 | 记录每个关系的状态与中文备注；结论绑定当前对象几何、打印尺寸、关联和已应用阈值；点重合只需作者解释，不自动移动数据 |
| 修改 | 选择标签，确认关联对象，填写横向/纵向毫米位移；应用后重新计算全部对象关系，避免只修一处造成另一处碰撞 |
| 恢复 | 使用撤销回到上一步的几何、尺寸、关联、已应用阈值与对应结论，历史记录保留；恢复原图也保留历史，失败输入不破坏已加载审查 |
| 导出 | 下载当前SVG、审查JSON和中文文本报告；JSON含原图、当前图、尺寸、阈值、审查依据和历史，可导入继续 |

建议先使用标签示例：原关联间隙1毫米，先横移2毫米会使另一侧留白仅2.5毫米，再上移8毫米后两侧保守间隙改善。练习完成后导出JSON并重新导入，确认备注与当前图保持。

移动标签、校准尺寸、更换关联或应用不同阈值后，受影响的人工结论转为“待审查”，原状态和备注显示在“历史审查记录”，不计入当前进度。请按新间距重新判断并填写当前备注；历史中的旧间距不能当作当前依据。已离开提示列表的关系也保留历史，重新出现时仍需审查。只修改阈值输入框尚未应用时，报告仍使用上次已应用策略。

本版本导出审查JSON版本2，恢复时对照重新测量的实际几何核验结论依据，不信任文件内的关系摘要。版本1没有几何依据，旧状态与备注保留为历史并要求重新审查；版本2中被修改的尺寸、图稿、关联或阈值同样会使旧结论失效。该对应检查用于防止误用旧判断，不提供文件作者身份认证。

## 支持与拒绝范围

支持SVG基本图元与路径、嵌套变换、标签组、可访问对象名称及TVL样本结构；浏览器测量对象几何，保留原路径。图中 `data-role="label"` 标签组与文本可移动，数据点不可通过本产品移动。没有对象身份时提供可追溯生成标识；关联不明时由作者确认。

活动内容、外部链接资源、不可信CSS、裁切/遮罩/滤镜、无法可靠理解的元素及非法数值会明确拒绝或显示不确定原因。大文件和过量对象有限制，详见界面错误信息。文字与任意路径边界为保守包围盒，不能推断真实触摸留白；字体不可用或文字显示替代时必须由作者复核。SVG内嵌字体是原图材料，产品不提供中文盲文转换。

打印时必须关闭驱动的自动缩放，并由实际设备确认纸张尺寸、字体及输出效果；审查尺寸是作者声明，不代表物理测量。PPTX、PDF、图片和任意专业图形编辑不在本产品输入范围。对不支持输入保留原文件，用原制作软件导出支持的SVG后再试。

## 保存与隐私

工作存在当前页面内存，关闭或刷新页面前请保存审查JSON；不承诺自动持久化。原SVG随审查JSON保存，便于回滚与核对。不要只保存截图。审查JSON和SVG可能含图形内容与备注，请按自己的资料管理方式保管。所有操作只在本机完成，收入$0、真实采用人数0。

JSON恢复支持12 MB以内、最多10000条人工关系记录和10000条历史记录；未操作的提示关系不会自动生成保存记录。导出前也校验相同限制，超限会明确提示且保留当前工作，不生成无法恢复的JSON。较大审查请先导出SVG与文本报告，在原制作软件中分图处理。

## 验证与剩余边界

本独立副本的 `tests/` 覆盖真实 TVL 来源、几何、标签修改与撤销、JSON/SVG 导出恢复、人工判断版本失效、安全输入和窄屏键盘操作。展示副本不附带原运行私有登记、模型日志和历史验收文件。界面截图属于页面观察，不代表实体触觉成功。

需要在自己的环境重跑检查时，在产品目录创建虚拟环境，安装 `requirements-dev.txt`，执行该环境的 `python -m playwright install chromium` 后，运行 `python -m unittest discover -s tests -v`。检查会开启并关闭自己的本机测试服务，不需要另开serve.py。Linux 环境还需 Chromium 系统运行库；本副本已在 Windows 原生 Python 与 Chrome 实测。若已有浏览器，可用 `TACTILE_CHROMIUM_EXECUTABLE` 指向其可执行文件。
