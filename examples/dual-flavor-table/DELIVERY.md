# 一桌双味 · 本地交接

让口味不同的同住者无需录入菜谱，选好现成整餐，就能取得一次采购、共享备料、各自调味的完整方案。原运行完成2轮产品工作；接续此前消费者探索，历史连续时间线共3轮，工作语言为简体中文。本次公开副本整理不增加历史轮次。

## 本机启动

在本产品目录运行；Windows 使用 `python`，macOS/Linux 使用 `python3`：

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

打开 **http://127.0.0.1:8080**。若端口被占用，可改成8081并访问对应地址；结束时在终端按 `Ctrl+C`。生产运行是纯静态文件，无需安装依赖或构建。不要双击 `index.html`，浏览器本地文件协议会限制模块加载。

验收期间预览是临时的，周期结束后会关闭，以上命令可自行重新启动。进度按浏览器和网站地址保存，换端口/浏览器前先下载备份。没有发布、部署、推送、账户或收费。

## 完整使用流程

| 步骤 | 操作与结果 |
| --- | --- |
| 1. 决定两组 | A/B各1–4人，总共2–6人。分别选择清淡、香辣或蒜香；人数多时分批，估时随之增加。 |
| 2. 筛选整餐 | 可用时间20–90分钟；选择整桌素食（蛋奶素）或排除明确食材。列表使用替换后的食材和当前人数估时；没有匹配时提示调整。 |
| 3. 生成 | 选择晚餐后生成。初次进入已有默认完整方案。修改设置是草稿，生成前保留旧方案；有勾选进度时会询问是否清除。 |
| 4. 采购备料 | 共享用量按总人数合并，两组最后调料按各组人数单列。勾选已有/已买材料；同名分组调料也有独立操作标识。 |
| 5. 做饭分味 | 依次启动米饭、备蔬菜、处理蛋白、分批做熟菜。共享底料完成后按人数分盘，清淡先盛，各用干净盘勺调味，不回共用炒锅；米饭和配菜保持基础味。 |
| 6. 保存携带 | 勾选实时存当前浏览器，刷新后恢复。整餐文字下载包含全部采购、步骤、分味和边界。打印可生成厨房用纸张或浏览器PDF。 |
| 7. 备份恢复 | 下载JSON进度备份。导入先验证应用、版本、配置和实际材料/步骤；错误或超大文件不会覆盖当前方案。有进度时导入先确认替换。 |
| 8. 再做一遍 | “重新开始勾选”确认后清进度、保留方案；生成不同配置时不把旧完成标记带入新方案。 |

## 菜单与适用条件

| 整餐 | 主菜共享原料 | 配菜与主食 |
| --- | --- | --- |
| 番茄豆腐 | 豆腐＋番茄 | 西兰花＋米饭 |
| 土豆鸡蛋 | 鸡蛋＋土豆 | 小白菜＋米饭 |
| 南瓜鹰嘴豆 | 预煮熟鹰嘴豆＋南瓜 | 菠菜＋米饭 |
| 蘑菇豆腐 | 豆腐＋蘑菇 | 胡萝卜＋米饭 |
| 胡萝卜鸡肉 | 鸡肉＋胡萝卜 | 西葫芦＋米饭 |
| 玉米鸡肉 | 鸡肉＋预煮熟玉米 | 卷心菜＋米饭 |

固定1名操作者、1口带盖炒锅、1台电饭煲，另备刀板、量秤/量杯、共享盛菜盆、分组碗盘和独立勺。鸡肉菜单另需食品温度计。设备容量须足够；主菜和蔬菜每批最多2份，6人要多次顺序炒制。

整桌素食把鸡肉换豆腐，土豆鸡蛋仍含蛋，不提供一组肉一组素混做。排除豆腐或鸡蛋时用熟鹰嘴豆替换，番茄可换南瓜，蘑菇可换西葫芦；替换原料仍被排除则该整餐不可用。熟豆不能用干豆直接替换，流程不含浸泡煮制。蒜/辣排除与对应口味冲突时要求改选，不偷偷改变选择。

每份米75克干重；蔬菜/豆腐/鸡肉按净重，熟豆按沥干熟重。厨房秤若不能精确称微量盐，可按清单减量并逐步试味；时间以实际设备和熟度为准。卡片与计划使用同一人数估时，部分6人套餐超过90分钟，不能在当前时间范围内选择。

主菜用水按每份60毫升计入清单，各批步骤明确本批用量；两份一批用120毫升，末批若只做一份用60毫升。每批只加一次本批主菜水，玉米原鸡肉、替换豆腐或熟鹰嘴豆都遵守同一分配。煮饭水、配菜水各自单列，不与主菜水混用。此次修复前下载的旧文字可能重复要求加水，请刷新页面后重新下载；原浏览器保存和JSON备份恢复会按配置重新生成步骤。

## 数据与失败恢复

本机存储键为 `dual-flavor-table-v1`，仅保存规范化配置与采购/步骤勾选，不上传数据。JSON用于恢复状态，文字用于离线照做。

| 现象 | 恢复方式 |
| --- | --- |
| 无匹配整餐 | 增加时间、减少人数或排除项，旧方案保留。 |
| 人数/时间超范围 | 根据中文提示修正，原方案和保存进度保留。 |
| 蒜香/香辣与排除冲突 | 改选清淡或修改排除项再生成。 |
| 上次存储损坏 | 默认方案仍可用，显示恢复说明；导入完整备份。损坏数据不用于生成内容。 |
| 浏览器无法保存 | 当前会话可用并提示保存失败；关闭前下载备份。 |
| 备份损坏/未知标记/超100KB | 拒绝导入，当前数据保留；选择产品导出的原始文件。 |
| 清浏览器、换设备或换端口 | 先下载JSON，在新入口导入；不自动跨设备同步。 |

## 实际边界

- 六套方案**尚未真实厨房试做或真人品尝**，不保证风味、总时长或开饭时间。锅容量、火力、切菜速度、米品种可能延长操作，实际熟度优先。
- 排除只针对计划原料，**不能保证过敏安全**；须核对每件包装的全部配料、过敏原/交叉接触提示和厨房器具残留。
- 生肉与熟食用具分开，鸡肉最后备料，之后清洁手、刀板和台面；鸡肉熟度以温度计确认而非颜色/分钟。一般原则参考 [CDC鸡肉食品安全](https://www.cdc.gov/food-safety/foods/chicken.html)，不能据此证明本产品菜谱已试做。
