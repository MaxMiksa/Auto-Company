# 本地核验引擎

`engine.js` 为无依赖 ES module，可直接由浏览器导入。原始 Python/DataComPy 实验保留在框架 `docs/evaluation/experiment`，此文件是完整本地产物的新实现，未改原实验。

## 输入与返回

| 接口 | 行为 |
|---|---|
| `parseCSV(text)` | 返回 `{headers, rows}`；rows 为列名到字符串的对象数组。支持 UTF-8 BOM、CRLF、引号内逗号/换行及双引号转义；拒绝空文件、空/重复表头、宽度不符、无闭合引号及 NUL。每表最多 20,000 数据行，原始 CSV 最多 5 MiB。错误为中文，可修正文件后重试。 |
| `audit(config)` | 返回可 JSON 序列化的状态、声明、检查、异常、缺证说明与生成时间；异常优先返回 `fail`，没有异常但存在缺证返回 `unknown`，其余 `pass`。 |
| `demoConfig(mode)` | 返回完整合成联系人/交易/多对多关联配置。`valid`、`broken`、`unknown` 均可另行编辑，不产生真实迁移或客户证据。 |
| `toCSV(report)` | 导出带 BOM 的异常与缺证清单。全部字段双引号转义，公式触发前缀及前导空白后的触发前缀加单引号保护。 |

`config` 包含 `project`、`scope`、`objects` 及 `relationships`。scope 的 `complete`、`identity`、`rules`、`snapshot` 必须严格为 `true`，`note` 为使用者范围说明；`scope.relationships` 默认要求关联验收，只有明确为 `false` 才将关联排除，此时整体仍为不可判定，并显示范围限制。没有所需关联表不能通过。对象提供源/目标数据表、源/目标身份列、字段映射数组，金额另须指定两端币种列。值映射 `map` 的方向为**目标值到源值**，例如 `{ "A": "active" }`。关联配置中的 `from.object` / `to.object` 指向对象名称，`source` / `target` 指向该关联表对应列，可选 `role: {source, target, map?}` 指定关系角色列及目标到源的值映射。报告保存 `config` JSON 快照供复核，不修改原配置。

## 比较边界

- 身份按原始字符串匹配，不去空白、不转数字；`001` 与 `1` 不相等。目标重编号须提供经核实的 `legacy_id`，不以邮件或顺序猜测。目标关联端点也必须先还原成对象所用旧 ID。
- 文本仅去首尾空白；邮件另转小写；日期仅接受有效 `YYYY-MM-DD` / `YYYY/MM/DD`，不猜地域格式或时区。上述转换须获得明确授权。
- 金额按普通十进制字符串规范化，仅消除无意义的前后零，不使用浮点、不自动四舍五入、不按总额抵消；每条记录核验金额与币种。默认精度为 2 位小数，`field.precision` 可明确指定 0 至 8 位；规范化后超出精度直接报异常，两侧同时超精度也不能通过。源金额与原始目标金额均须满足格式和精度要求，授权值映射不能掩盖原始目标金额错误。拒绝指数、千位逗号、货币符号。空字符串两端均空视为相同；需要强制必填的业务规则不在本次范围内。非空无效金额/日期报异常。字段比较仅适用于成功唯一配对的记录；缺失或重复身份记录先报告身份问题。
- 缺少表、列、稳定身份、快照、完整范围、字段授权、金额币种配置均保留不可判定。没有稳定身份时不进行跨表配对；没有转换授权时不运行字段归一化比较。
- 关系比较两端身份对、可选的角色和出现次数，检测孤儿、重复、缺失及新增/错挂。配置角色后不同角色为不同关联，同角色重复仍报异常；未配置角色时报告明确提示仅核验端点，不含角色语义。角色文本去首尾空白与值映射同样需要转换授权。
- 报告通过只说明所提供且明确配置的范围通过。工具不独立证明声明为真，不读取 CRM，不生成放行批准，不宣称整个迁移成功。

## 异常标识

`empty-key`、`duplicate-key`、`missing-record`、`extra-record`、`field-mismatch`、`invalid-field`、`currency-mismatch`、`orphan-relationship`、`duplicate-relationship`、`missing-relationship`、`extra-relationship`。每条包括对象、身份或关联、字段、源值、目标值和中文说明。

实际运行检查由协调器通过项目 runner 统一执行，本实现文档不预先声明检查通过。
