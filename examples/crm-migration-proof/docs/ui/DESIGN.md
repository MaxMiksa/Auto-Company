# 验收工作台设计与核心流程

使用框架 `frontend-design`，面向独立 CRM 实施顾问准备迁移交接的任务。风格采用纸面审计台：暖灰纸面、深绿墨色、少量亮绿提示，编号与表格组织依据；“先对齐，再比较”是主任务。

三步操作为材料及映射、证据边界、核验及交接。源/目标并排；小屏改纵向排列，不挤压文件、字段和规则控件。未证实声明默认不勾选，样例明确为合成数据。失败与未知分别用红/土黄并配中文文字，不依赖颜色表达结论。焦点可见、表格可滚动、结果/错误有朗读区域，支持减少动效。

标志为两页对齐材料与单条验收笔迹的简洁几何形，输入 `icon.svg`；页面品牌及 favicon 引用程序拥有的 `auto-company-icon.svg`。当前框架未提供 `docs/product-logo-prompt.md`，依据用户提示中的设计要求实施，不创建或修改程序图标。使用本机字体，不从外部加载资源。
