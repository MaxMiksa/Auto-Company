# 迁移验收测试策略

本地产品检查的是用户提供的 CSV、身份映射和已声明迁移规则。最严重的风险是把异常或缺失证据显示成通过，其次是因错误解析、金额舍入或导出执行公式而改变原始证据。合成数据检查不代表真实客户采用，也不能证明导出范围完整。

| 风险 | 核验方式 | 预期边界 |
|---|---|---|
| 合法转换被误报 | 独立字段命名、重编号、状态与日期转换 | 授权规则内通过，明确显示核验范围 |
| 数量/总额掩盖破坏 | 逐键遗漏、重复、错挂、金额相抵、前导零、孤儿、状态、币种和分以下精度 | 每类破坏产生可定位异常；净额相同不能掩盖逐笔差异 |
| 缺证被当作通过 | 缺身份映射、局部导出、缺关联文件、未确认转换；混合已知异常 | 不可判定与已知异常均保留，不能只返回第一个问题 |
| CSV 改变证据 | BOM、中文、引号逗号、quoted newline、空/重复表头、坏行 | 文本保真；结构错误有可恢复提示 |
| 错误金额/日期/标识 | 空键、重复关联、非法金额、非法日期 | 拒绝或明确列出异常，不通过隐式类型转换猜测结果 |
| 业务精度与关联角色被忽略 | 双侧相同分以下金额、授权四位单位、同端点不同角色、角色交换 | 默认两位有效小数；显式精度获授权后比较；角色参与关联身份 |
| 导出诱导执行 | HTML 字符串与电子表格公式前缀 | 页面按文本显示；导出在表格中不会执行公式 |
| 只有演示可用 | 非演示业务数据、不同 CSV 列名与用户配置 | 完整导入、配置、审查、修正、导出核心流程可用 |
| 重绘无声丢失输入 | 双侧先填、其他对象与关联表草稿；应用、字段增删及类型切换、对象增删、对象改名、关联表增删 | 逐侧文本与用户选择的折叠状态保留；未应用状态不能被已应用材料掩盖 |
| 失败或迟到读取覆盖新草稿 | 非法粘贴、非法上传、成功上传替换本侧、清空草稿、上传期间再次输入 | 失败可纠正；空草稿仍需显式处理；迟到读取不能清除后来输入；旧报告与下载入口失效 |

自动化采用 Node 原生 `node:test` 验证真实数据行为，不按源代码断言或文件存在判断功能完成。协调器通过正式交付检查工具执行并保存原始结果；本文件仅描述检查设计，不预填通过次数或验收结论。旧实验成功与失败记录保持原样。

CSV 上限也通过真实字符串构造核验：超过 20,000 数据行、UTF-8 编码超过 5 MB 或含空字符时应拒绝并给出错误提示。读取大小不是将字符数误当字节数。

浏览器探索重点是：无文件开始使用、真实 CSV 导入后映射选择、缺证据提示、错误恢复、结果中的用户文本显示、证据下载、修改输入后的旧结果失效及窄屏可操作性。浏览器脚本使用本地构造 CSV，不注册、不登录、不接触任何真实 CRM 或外部人员。

`tests/browser.test.js` 通过正式预览 URL 运行已安装的 Chromium，实际上传两对象与带角色关联的独立 CSV，填写列名和值映射，从缺证到补齐声明通过，再制造逐笔异常。脚本真实下载并读取 JSON、CSV、HTML，核对前导零、文件哈希、输入快照、公式防护和恶意 HTML 文本转义；还检查 390px 页面、三种样例与清空恢复。未应用粘贴时不得再核验旧表；用浏览器文件读取的人工延迟模拟慢读，核对读取期间核验按钮与旧报告失效。执行所需环境为 `PRODUCT_PREVIEW_URL`；仅协调器通过正式 runner 执行。

本次针对父验收发现的草稿丢失新增四个功能子用例，保留原四个用例。每个新增用例重置工作区，避免旧对象、声明或字段映射污染结果。单联系人用例真实上传双方有表头、零数据行的关联 CSV，配置端点及角色并明确声明无关系；不靠关闭关联检查获得通过。跨卡片用例使用两对象及带角色的真实构造关联，核对完整导出的六份材料。

草稿保真检查包含 `<>&`、双引号、字段内换行、草稿首行换行以及恶意 HTML 文本；既检查文本框完整值，也检查页面没有执行该文本。失败后保留草稿和未应用提示，修正后先观察异常报告、再恢复通过。成功上传只清本侧草稿；清空文本不会自动复用旧材料。文件读取人为延迟期间输入新草稿后，最终下载证据必须使用后来显式应用的文本，不含迟到文件。

这些自动化检查验证已知预期，不能替代探索性测试或证明零缺陷。正式执行结果与用例数以协调器通过原交付合同产生的新 runner 记录为准；本文只记录检查设计。当前本地依赖为产品安装的 Playwright 1.63.0 与临时浏览器运行库 `/tmp/crm-proof-browser-libs/usr/lib/x86_64-linux-gnu`，通过 `LD_LIBRARY_PATH` 使用临时库，不修改系统服务。正式预览保持打开时，协调器从框架根目录使用 `PRODUCT_PREVIEW_URL=<正式预览地址> LD_LIBRARY_PATH=/tmp/crm-proof-browser-libs/usr/lib/x86_64-linux-gnu python3 scripts/core/delivery_contract.py check --criterion browser-flow --adapter node-test -- tests/browser.test.js` 执行。

当前检查范围不包含真实 CRM 导出真实性、合法合并或拆分、活动与附件、非双射身份、多时点快照及超大文件性能。若产品明确限制范围，测试验证说明能被用户看到；范围限制不能替代已承诺的核心流程。
