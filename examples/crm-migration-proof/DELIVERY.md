# 迁移验收工作台 · 本地交接

这是供 CRM 实施顾问使用的完整本地浏览器工作台。核心结果是可复核的记录、字段、金额和关联验收证据，不是全 CRM 完整性保证或客户验收批准。

## 启动与停止

需要 Node.js 22 或更新版本和现代浏览器；正常使用不需要安装开发依赖、账户或联网。

在项目目录运行：

```sh
npm start
```

打开 <http://127.0.0.1:8765>。端口被占用时使用 `node serve.cjs 8766` 换用空闲端口，并用相同端口访问。使用完在该终端按 Ctrl+C 停止。不要直接双击 HTML；本机 HTTP 才能可靠加载模块及计算哈希。

## 完整核心任务

| 步骤 | 操作与结果 |
|---|---|
| 1. 准备材料 | 同一范围、可比快照的源/目标 UTF-8 CSV；每表最多 5 MB、20,000 行 |
| 2. 配置对象 | 上传或粘贴 CSV；选源唯一 ID 和目标对应旧 ID，添加字段映射、类型、目标值到源值规则 |
| 3. 核验金额 | 选择金额字段、允许小数位及两侧币种；逐笔精确比较，不舍入、不按总额抵消、不换汇 |
| 4. 配置关联 | 导入两端关联 CSV，选择对象端点列及可选角色；目标端点先用可靠新旧映射还原为对象选中的旧 ID |
| 5. 记录范围 | 只勾选有依据的完整导出、稳定身份、授权规则及快照声明；写明导出范围、批准依据及排除项 |
| 6. 生成证据 | 查看每项检查、全部未知及异常定位；已知异常为失败，缺证且无明确异常为不可判定 |
| 7. 交接与重跑 | 下载 JSON、异常 CSV、可打印 HTML；修正并重新生成。任何材料/规则变更使旧页面结果失效 |

初次可载入“合法迁移 / 含异常 / 缺证据”合成样例。可以添加对象与关联表、使用不同列名，结果不依赖硬编码示例。全部界面和用户说明采用简体中文，JSON 字段、列名、命令和技术标识按协议保持原文。

详见 [中文使用说明](docs/USAGE.md)。

## 输出与保管

JSON 含完整输入解析快照、映射/规则、范围声明、输入文件 SHA-256、配置 SHA-256、生成时间、检查及全部异常/未知。真实上传文件使用原始 UTF-8 内容哈希；合成示例明确标记为解析数据 JSON 的哈希，不冒充原始导出文件。

CSV 为带单个 UTF-8 BOM 的异常及未证明项清单，防止源值在表格软件中被当作公式。HTML 包含全部异常、范围、配置及输入快照，独立打开即可通过浏览器打印，无脚本和外部资源。页面最多展示前 300 个异常，下载不截断。

数据不上传、不写浏览器持久存储；刷新或清空后工作区消失。下载文件含个人资料与完整输入，请按客户项目规范保管。哈希用于识别本次材料，不能证明材料完整、第三方签署或业务批准。工作台不修改源 CSV。

## 验证与恢复

核验逻辑使用真实 Node 原生测试；浏览器流程使用真实 Playwright Chromium，通过正式交付 runner 记录结果。程序生成的报告与最新状态以框架交付记录为准，本文不预填成功数量。

复跑逻辑：`npm test`。复跑浏览器：先按 README 安装开发测试依赖，启动本机服务器，再运行：

```sh
PRODUCT_PREVIEW_URL=http://127.0.0.1:8765 node --test tests/browser.test.js
```

CSV 格式、编码或大小错误会清除该侧旧输入并提示；纠正文件后重新上传。修改粘贴框后须点击“应用粘贴内容”，未应用不能生成旧表结论。映射 JSON 错误须修正后重试；缺表、缺列或证据不足进入不可判定，不自动猜测身份、舍入金额、补日期或代为批准。

可以先填写多个对象和关联表的两侧 CSV，再逐侧应用。应用其中一侧、增删字段映射或调整其他对象时，其他未应用的草稿和粘贴区展开状态会保留；未应用提示也会保留。粘贴成功后该侧文本仍可查看或修改，错误时保留原草稿供纠正。成功上传文件会替换该侧材料并清空该侧粘贴草稿，其他侧不受影响；上传失败不会丢失已有粘贴草稿。主动移除对象/关联表、清空工作区、载入样例或刷新页面会移除相应草稿，草稿不写入持久存储。

## 剩余边界

支持一对一稳定身份、明确字段转换与多对多端点/角色比较。未选择字段、目标原生新 ID 唯一性、业务必填规则、活动/附件、合法实体合并或拆分、自由业务逻辑、超大文件及跨币种折算未自动验收。关联未纳入时保留未证明项；含角色的关系应配置角色列，不能把仅比较端点当角色已正确。

“所给材料通过”依赖使用者声明，不能证明两端同时遗漏的数据，也不能代替人工复核或客户验收签字。本地与合成测试不证明真实使用、成交或盈利；现有收入为 $0、用户为 0。无外联、注册、交易、发布或部署。
