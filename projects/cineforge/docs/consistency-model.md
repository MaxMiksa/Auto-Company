# 一致性与定位数据模型

镜场把「像不像专业片子」拆成可锁定、可跨镜继承的字段。编译提示词时这些字段必须原样写入，禁止被风格词冲掉。

## Scene lock（场景锁）

| 字段 | 含义 |
| --- | --- |
| `sceneId` | 绑定的场景素材 ID |
| `name` | 场名（如「雨夜便利店」） |
| `space` | 空间几何：室内外、层高、进深、主要墙/窗/柜台位置 |
| `timeOfDay` | 时间 |
| `weather` | 天气 |
| `light` | 主光来源、色温、是否可改 |
| `props` | 场内不可移动/必须出现的道具 |
| `immutable` | 本场禁止变化的清单（墙色、招牌、地板、窗外） |

跨镜：下一镜必须继承 `sceneId`、`space`、`light`、`immutable`。只允许任务明确要求的光/天气变化。

## Task lock（任务锁）

| 字段 | 含义 |
| --- | --- |
| `goal` | 本轮要完成的戏剧或交付任务（一句） |
| `success` | 观众必须看见/听见什么才算完成 |
| `forbidden` | 禁止偏移（换题、换人、换场、加旁白等） |
| `durationSec` | 目标时长 |
| `aspectRatio` | 画幅 |

跨镜：`goal` 与 `forbidden` 全程不改。单镜只承担 `goal` 的一个可见节拍。

## Space / blocking（空间与定位）

每位上场人物一条：

| 字段 | 含义 |
| --- | --- |
| `characterId` | 人物素材 |
| `stance` | 站位（相对场景锚点：柜台内侧、门口、后景桌） |
| `bodyFacing` | 身体朝向 |
| `eyeline` | 视线落点（另一角色、窗外、镜头） |
| `inOut` | 进出画（已在画内 / 从左入 / 从门出） |
| `depth` | 前/中/后景 |
| `camera` | 机位（建立/中景/过肩/特写）与运动 |
| `lensFeel` | 镜头感（35mm 贴近、85mm 压缩等，给编译器用） |

跨镜：未宣布换位时，继承站位、朝向、视线、深度。机位可改，但必须写清新机位相对旧空间的关系。

## 素材三镜头契约

每条人物 / 场景 / 物品：

- `shots.wide` 建立或全身/全貌
- `shots.medium` 中景或 3/4
- `shots.close` 脸、材质、招牌等身份锚点
- `description` 不可变特征（疤、发卡、墙皮剥落、杯口缺口）
- `doNotTransfer` 禁止带到成片的维度（例如物品图的背景灯）

成片引用时写清：身份以三镜头为准，背景/光以场景锁为准。

## 声音与人生克隆

- `VoiceProfile`：样本、音色描述、可用范围（对白/旁白）
- `LikenessClone`（人生克隆）：已授权形象 + 绑定人物素材 + 绑定默认音色 + 授权声明
- `DialogueLine`：`characterId` + `voiceId` + 台词 + 情绪 + 大致时间

编译时每句对白必须带「谁、用哪条声线、情绪、口型意图」。未绑音色的人物不得默认为旁白。

## 跨镜继承规则（摘要）

必须带入下一镜：scene lock 的空间/光/不可变项；task lock 的目标与禁区；未改位角色的站位/朝向/视线；人物与物品的三镜头身份；已选音色。

可以改、但必须显式写：机位、镜头运动、哪一句对白、谁进出画。

禁止静默改：脸、场、主道具、任务题、声线归属。
