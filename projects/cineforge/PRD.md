# 镜场 CineForge · 产品说明

面向非专业影视人员，用白话生成专业级短视频。交互参考即梦（文生/图生/首尾帧/参考主体/任务队列），**不使用即梦商标与官方素材**。

## 用户

不会写分镜、不会写专业提示词的创作者。他们知道「要一段什么感觉的片子」，系统负责把意图变成可锁定的场、戏、空间、人、声，再交给成片模型。

## 主路径

1. 在素材库建人物 / 场景 / 物品（各 3 机位图 + 描述）
2. 可选：声音克隆、人生克隆，并把音色绑到人物
3. 新建任务：写白话意图，锁定场景 / 任务 / 空间
4. 写台词：每句对应人物 + 音色
5. 后台 AI 编译导演级提示词（用户不写专业长词）
6. 提交成片（MiniMax-H3 或 Seedance 2.0），队列里看状态与预览，失败可重试

## 功能清单（对标即梦 + 我们的差异）

| 能力 | 即梦常见形态 | 镜场要求 |
| --- | --- | --- |
| 文生视频 | 一句话出片 | 白话意图必须先编译进 scene/task/space 锁 |
| 图生 / 参考图 | 上传参考 | 参考来自素材库三镜头，身份契约明确 |
| 首尾帧 | 两张图过渡 | 支持；锁场信息不丢 |
| 主体参考 | 角色/物品 | 人物、场景、物品三类，各 3 镜 |
| 分镜 / 多镜 | 故事板 | 跨镜继承场景锁、任务锁、空间锁 |
| 任务队列 | 生成历史 | 状态、预览、重试、所用提示词可回看 |
| 声音 | 配乐/对白 | **声音克隆 + 台词绑定人物与音色** |
| 数字人 | 较少作为一等能力 | **人生克隆**：形象 + 声线 + 授权声明 |

差异：一致性不是滤镜，是硬锁。用户看到的是「这场不能变、这句谁说、人站哪」，而不是一堆风格形容词。

## 本轮范围

可运行 MVP：设置切换模型、素材三镜头、锁面板、台词绑人绑声、后台编译、成片入队（有钥真生成，无钥 mock）。

不做：支付、复杂账号、公网强制部署、多集自动剪辑、精细调色。
